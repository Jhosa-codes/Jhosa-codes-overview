## Projetos em destaque

### [Compilador Mini-Lang](https://github.com/Jhosa-codes/Compiladores)
Projeto educacional de um compilador em Python para uma linguagem própria. Implementa etapas como análise léxica, sintática e semântica, construção de AST, interpretação e geração de código Python.

**Tecnologias:** Python

### [Barbearia App](https://github.com/Jhosa-codes/barbearia-app)
Aplicativo Flutter em desenvolvimento, organizado em funcionalidades como autenticação, serviços, profissionais, reservas e perfil, com pontos de integração com Supabase.

**Tecnologias:** Flutter, Dart e Supabase  
**Processo:** projeto desenvolvido com vibe coding e assistência de IA. O código e as integrações precisam de revisão e validação antes de uso em produção.

### [Currículo Front-end em HTML](https://github.com/Jhosa-codes/projeto_curriculo_formato_ats_front_end_ferrametas)
Página responsiva de currículo profissional feita com HTML, CSS e JavaScript, com seções para formação, projetos e competências.

**Tecnologias:** HTML, CSS e JavaScript

### [Analisador Educacional de Sintomas](https://github.com/Jhosa-codes/Codigo-Covid-19)
Aplicação de linha de comando em Python que usa respostas sobre sintomas para calcular uma pontuação heurística e exibir um gráfico com Matplotlib. É um exercício educacional, não uma ferramenta de diagnóstico médico.

**Tecnologias:** Python e Matplotlib
